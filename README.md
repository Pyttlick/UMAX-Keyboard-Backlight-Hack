# 💡 UMAX Keyboard Backlight Hack (No Software Required)

### 🎁 A gift to humanity from an anonymous UMAX laptop user

Some UMAX laptops automatically turn off keyboard backlighting after a few seconds of inactivity, with no way to change this in BIOS, drivers, or Windows settings.  
This simple mechanical hack fixes it — **no software, no system modifications, no extra power usage**.

---

### 🧰 What You Need
- 1× small strip of transparent (rigid) office plastic sheet
- A precision screwdriver or something thin to gently pry up a key
- A UMAX laptop with a working `Scroll Lock` key (or other low-impact key)

---

### ⚙️ How to Do It
1. Carefully remove the `Scroll Lock` key.
2. Insert the plastic strip over the membrane so that it slightly presses the contact, keeping the key in a "pressed" state.
3. Tuck the ends of the strip under nearby keys or edges to hold it in place.
4. Optionally snap the keycap back on — your keyboard backlight will now stay **permanently on**.
5. The system is unaffected (Scroll Lock typically has no function in modern software).

---

### 🧪 Tested On:
- Works even after a full reboot
- Does not interfere with typing, browser usage, or any application
- Fully reversible — just remove the strip and put the keycap back

### 👨‍🔧 Why It Works
The laptop interprets any keypress as "user activity", keeping the keyboard backlight on. Scroll Lock is an ideal candidate because it does almost nothing in modern OS environments.
